AI가 80년 된 수학 난제를 풀었어요. 그것도 수학 전용 모델이 아닌 범용 모델로

• 폴 에르되시가 1946년에 제시한 '평면 단위 거리 문제'는 거의 80년간 미해결 상태였어요. 격자 구조가 최적이라는 믿음이 정설이었는데, OpenAI의 범용 추론 모델이 이 믿음을 정면으로 뒤집는 반례를 무한히 생성해냈죠.
• 증명 방식이 놀라워요. 기초적인 기하학 문제에 대수적 수론(algebraic number theory)의 고급 개념을 적용했는데, 이 아이디어 자체가 외부 수학자들로부터 '독창적인 추론'이라는 평가를 받았어요. 필즈상 수상자 팀 가워스도 공식적으로 결과를 지지했고요.
• 이 모델은 수학 문제 풀이에 특화된 시스템이 아니에요. 특정 분야에 파인튜닝하지 않은 general-purpose reasoning model이 수학 하위 분야의 핵심 난제를 자율적으로 해결한 건 이번이 처음이에요.

💡 오늘의 인사이트

솔직히 말하면, 이 뉴스가 좀 묘하게 느껴지지 않나요. 우리가 매일 쓰는 AI 도구가 단순히 코드 자동완성을 넘어 '아무도 생각 못 했던 방식'으로 문제를 푸는 단계에 접어들고 있어요. 당장 내 업무에 드라마틱한 변화가 생기는 건 아니지만, 지금 우리가 AI를 어떻게 협업 도구로 활용하고 있는지 한 번쯤 점검해볼 시점인 것 같아요. 반복 작업 자동화 수준에서 멈추고 있다면, 조금 더 복잡한 문제를 던져봐도 괜찮을 것 같거든요.

VS Code 확장 하나로 GitHub 내부 저장소 3,800개가 털렸어요

• GitHub 직원이 악성 VS Code 확장을 설치한 것이 시작이었어요. 결과적으로 GitHub 내부 저장소 약 3,800개가 유출됐고, 해커 그룹 TeamPCP는 탈취한 데이터를 최소 5만 달러에 팔겠다고 선언했어요.
• TeamPCP는 이번이 처음이 아니에요. GitHub, PyPI, NPM, Docker 등 개발자 플랫폼을 겨냥한 공급망 공격 이력이 있는 그룹이에요. 이번에 유출된 코드가 향후 더 큰 공격의 재료로 쓰일 가능성도 있어요.
• VS Code Marketplace의 악성 확장 문제는 이번이 처음도 아니에요. 과거에도 자격증명을 탈취하거나 크립토마이너를 설치하는 트로이목마 확장들이 발견된 적 있어요. GitHub은 해당 확장을 마켓에서 제거하고 감염된 기기를 격리했지만, 고객 데이터 침해 여부는 계속 조사 중이에요.

💡 오늘의 인사이트

팀 내에 설치된 VS Code 확장 목록을 마지막으로 확인한 게 언제인지 기억나요. 아마 대부분 기억 안 나실 거예요. 확장 하나가 회사 내부 코드베이스 전체의 접근권을 가질 수 있다는 걸 생각하면, 꽤 서늘한 일이에요. 팀 차원에서 허용 확장 목록을 관리하거나, 최소한 설치 전 게시자 검증 습관만 만들어도 리스크를 크게 줄일 수 있어요. 오늘 팀 채널에 가볍게 공유해보는 건 어떨까요.

Flipper Zero의 형이 나왔어요. 이번엔 8코어 CPU에 6 TOPS NPU까지 달고

• Flipper One은 Rockchip RK3576 8코어 CPU, 8GB RAM, 64GB 스토리지를 품고 있어요. 여기에 Raspberry Pi RP2350B MCU가 서브 프로세서로 함께 들어가 있어서, 고수준 연산과 저수준 하드웨어 제어를 동시에 처리할 수 있는 구조예요.
• 확장성이 인상적이에요. M.2 슬롯 하나로 PCIe, USB, SATA, I2C 등 다양한 인터페이스를 지원하고, 듀얼 기가비트 이더넷, WiFi 6, HDMI 2.1까지 갖추고 있어요. 포켓 사이즈 기기치고는 꽤 진지한 스펙이에요.
• 6 TOPS NPU가 탑재돼 INT4부터 TF32까지 다양한 데이터 포맷을 지원해요. 엣지에서 경량 AI 추론을 직접 돌릴 수 있다는 뜻인데, 보안 리서치나 IoT 프로토타이핑 용도로 흥미로운 조합이에요. 다만 스펙 일부는 아직 확정 전이라 최종 출시 전에 바뀔 수 있어요.

💡 오늘의 인사이트

Flipper One이 매력적인 이유는 스펙 자체보다 '한 기기에서 고수준 소프트웨어와 저수준 하드웨어를 동시에 다룰 수 있다'는 컨셉에 있어요. 하드웨어 해킹이나 보안 리서치에 관심 있는 분이라면 눈여겨볼 만해요. 아직 개발 중이라 실제 구매까지는 시간이 걸리겠지만, 스펙 페이지 북마크 해두는 건 공짜니까요.
