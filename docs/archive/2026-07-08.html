WAVE 01 222 pts · 50 comments

GPU 없이도 내 목소리를 만든다, Kokoro TTS

• Kokoro는 82M 파라미터짜리 TTS 모델이에요. GPU 없이 CPU만으로 돌아가고, Docker 컨테이너 하나면 바로 쓸 수 있어요. 영어, 중국어, 힌디어 포함 50개 이상의 목소리를 지원해요.
• OpenAI Speech API와 호환되는 인터페이스를 제공해요. 기존에 OpenAI TTS를 쓰던 코드라면 엔드포인트 주소만 바꿔도 그대로 붙어요. 사이드 프로젝트에 음성 기능 넣고 싶었는데 API 비용이 걱정됐다면, 이게 딱이에요.
• AMD Ryzen 7 기준으로 1.5초, M2 Pro에서는 4.5초 정도 걸려요. 실시간 대화보다는 오디오 파일 생성 용도에 더 잘 맞아요. 컨테이너 이미지가 5GB라는 점은 미리 알아두세요.

💡 오늘의 인사이트

클라우드 TTS API는 호출할 때마다 돈이 나가고, 텍스트가 외부 서버로 나간다는 찜찜함도 있죠. Kokoro는 그 두 가지를 한 번에 해결해요. 사내 문서를 음성으로 변환하거나, 개인 정보가 담긴 텍스트를 처리해야 하는 상황이라면 로컬 TTS가 진짜 현실적인 선택이 될 수 있어요. 5GB 이미지 크기가 부담스럽다면, 필요한 언어 모델만 골라서 빌드하는 방식도 고민해볼 만해요.

WAVE 02 655 pts · 161 comments

지도 앱을 직접 고친다는 게 이런 느낌이에요, StreetComplete

• StreetComplete는 OpenStreetMap에서 빠진 정보를 퀘스트 형태로 보여주는 앱이에요. 내 주변에 어떤 데이터가 없는지 지도 위에 표시해줘요.
• 별도 편집기 없이도 현장에서 간단한 질문에 답하는 것만으로 기여가 완료돼요. 기여 내역은 내 이름으로 직접 OpenStreetMap에 반영돼요.
• 개발자 입장에서 보면, 오픈소스 지도 데이터를 쓰는 서비스를 만들 때 데이터 품질 문제로 고생한 경험이 있을 거예요. 이 앱은 그 데이터를 직접 채울 수 있는 가장 쉬운 방법이에요.

💡 오늘의 인사이트

우리가 매일 쓰는 지도 앱 뒤에는 수많은 사람들이 직접 걸어다니며 채운 데이터가 있어요. StreetComplete는 그 기여의 문턱을 확 낮춘 사례예요. 기술적으로도 배울 게 있어요. 복잡한 편집 UI 대신 퀘스트라는 단순한 인터랙션으로 기여를 유도한 UX 설계가 인상적이에요. 내가 만드는 서비스에서도 사용자의 기여를 이끌어내야 한다면, 이 앱의 구조를 한 번 뜯어보는 걸 추천해요.

WAVE 03 384 pts · 128 comments

EU가 내 메시지를 읽으려 한다면, 어떻게 될까요

• EU에서 추진 중인 Chat Control은 두 가지 버전이 있어요. 1.0은 자발적 메시지 스캔 법안으로 2026년 4월에 만료됐고, 2.0은 의무 스캔을 포함한 영구 법안으로 협상이 계속되고 있어요.
• 핵심 쟁점은 E2E 암호화 통신과 의심받지 않은 일반 사용자의 메시지까지 스캔할 수 있느냐예요. 의회는 법원 명령과 용의자 한정 탐지를 요구하고, 이사회는 광범위한 자발적 탐지를 원해요. 다섯 번의 협상이 모두 결렬됐어요.
• 만료된 1.0을 이사회가 패스트트랙으로 부활시키려는 움직임도 있어요. 막으려면 의회에서 절대 다수인 361명의 찬성이 필요해요. 규제 불확실성이 계속되는 상황이에요.

💡 오늘의 인사이트

이건 유럽 얘기지만, 남 얘기가 아니에요. 우리가 만드는 서비스에 메시징 기능이 있다면, 언젠가 비슷한 규제가 요구 사항으로 들어올 수 있어요. E2E 암호화를 설계에 넣을지 말지는 기술 결정이기도 하지만, 이제는 법적 리스크와도 연결된 문제예요. Chat Control 논의를 가볍게 지켜보면서, 내 서비스의 데이터 처리 구조를 한 번 점검해보는 계기로 삼아보세요.
