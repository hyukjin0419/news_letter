💡 오늘의 인사이트

OS 포팅을 출시 당일에 끝낸다는 건 단순한 실력의 문제가 아니에요. 업스트림 변경 사항을 미리 추적하고, 테스트 환경을 미리 갖춰두는 준비의 결과예요. 내가 의존하는 외부 라이브러리나 플랫폼의 릴리즈 노트를 미리 구독해두는 습관, 생각보다 훨씬 큰 차이를 만들어줘요.

로컬 AI 모델, 이제 진짜 쓸 만해졌어요

• M2 맥 64GB 환경에서 Gemma 4 26B 모델로 코드 리팩토링, 린팅, 유닛 테스트 생성, 저장소 부트스트래핑을 실제로 완료했어요. 프론티어 모델 대비 약 75% 수준의 정확도와 속도라고 하는데, 이 정도면 충분히 실용적이죠.
• LM Studio나 Ollama 같은 도구 덕분에 로컬 모델 세팅이 예전보다 훨씬 쉬워졌어요. API 키 없이, 비용 걱정 없이, 내 코드가 외부로 나가지 않는 환경을 직접 만들 수 있어요.
• 다만 주의할 점도 있어요. K-V 캐시가 RAM을 많이 잡아먹고, 에이전틱 워크플로우는 아직 프로덕션 전 단계예요. 보안을 위해 Docker 컨테이너 안에서 격리 실행하는 걸 권장해요.

💡 오늘의 인사이트

클라우드 AI에 코드를 붙여넣을 때마다 찜찜했던 분들 많을 거예요. 로컬 모델이 이제 그 불편함을 해소해줄 수 있는 수준이 됐어요. 당장 프로덕션 코드에 쓰기보다는, 먼저 반복적인 테스트 작성이나 보일러플레이트 생성 같은 작업부터 맡겨보세요. 생각보다 빨리 손에 익을 거예요.

curl 없는 컨테이너에서 HTTP 요청 보내는 방법, 알고 계셨나요?

• /dev/tcp/host/port는 실제 파일 시스템 경로가 아니에요. bash가 내부적으로 TCP 소켓을 열어주는 가상 경로예요. printf로 raw HTTP 요청을 써 넣고 cat으로 응답을 읽어올 수 있어요.
• curl도 wget도 없는 최소화된 컨테이너 환경에서 디버깅할 때 요긴하게 쓸 수 있어요. 단, 연결이 끊기지 않도록 Connection: close 헤더를 꼭 넣어줘야 해요. 안 그러면 터미널이 그냥 멈춰요.
• 한계도 명확해요. TLS를 지원하지 않아서 HTTPS는 안 되고, --enable-net-redirections 플래그로 컴파일된 bash에서만 작동해요. dash나 zsh에서는 쓸 수 없어요.
