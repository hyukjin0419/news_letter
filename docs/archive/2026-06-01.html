Cloudflare가 당신의 브라우저를 봇으로 오해하는 이유

• Cloudflare Turnstile이 봇 탐지에 WebGL 기반 기기 핑거프린팅을 쓰는데, WebKit-GTK는 프라이버시 보호 차원에서 이 기법을 원천 차단해요. 결과적으로 해당 브라우저 사용자는 Turnstile이 붙은 사이트에서 무한 루프에 빠져버리죠.
• Firefox도 안심할 수 없어요. privacy.resistFingerprinting 설정이 기본값으로 꺼져 있고, WebGL 핑거프린팅 보호 기능에도 허점이 있어서 GPU 특성이 여전히 노출될 수 있어요.
• 보안과 프라이버시가 충돌하는 전형적인 사례예요. 봇을 막으려는 Turnstile과 추적을 막으려는 WebKit이 서로 정반대 방향을 바라보고 있는 거죠.

💡 오늘의 인사이트

서비스에 Cloudflare Turnstile을 붙이고 있다면, 일부 사용자가 아무 잘못 없이 접근 자체를 못 하고 있을 수 있어요. 특히 리눅스 환경에서 WebKit 계열 브라우저를 쓰는 개발자나 파워 유저라면 더욱 그렇죠. 봇 방어 솔루션을 도입할 때는 '어떤 사용자가 의도치 않게 막히는가'를 꼭 같이 따져보는 습관을 들이면 좋겠어요.

WAVE 02 256 pts · 90 comments

아이폰에서 직접 이미지를 생성하는 시대가 열렸어요

• PrismML이 공개한 Bonsai Image 4B는 1비트 양자화 모델로, 트랜스포머 크기를 기존 대비 8.3배 줄였어요. iPhone 17 Pro Max에서 512x512 이미지를 약 9.4초 만에 생성하는, 같은 파라미터 규모에서는 최초의 온디바이스 이미지 모델이에요.
• 1비트(1.125 bits/weight)와 삼진수(1.71 bits/weight) 두 가지 버전이 있어요. 삼진수 버전은 용량이 조금 더 크지만 시각적 품질과 프롬프트 충실도가 더 높아요. 배포 용량은 각각 3.42 GB, 3.88 GB로, 원본 FLUX.2 Klein 4B의 15.97 GB와 비교하면 엄청난 차이죠.
• Apache 2.0 라이선스로 가중치와 코드가 모두 공개되어 있고, Apple Silicon에서는 MLX, CUDA 환경에서는 Gemlite 커널을 활용해요. iOS 앱 Bonsai Studio로 바로 테스트해볼 수도 있어요.

💡 오늘의 인사이트

클라우드 API 호출 없이 기기 안에서 이미지를 만들 수 있다는 건, 개인정보 보호가 중요한 서비스나 오프라인 환경에서 새로운 가능성을 열어줘요. 아직 품질 면에서 풀 프리시전 모델과 차이가 있긴 하지만, 온디바이스 AI의 실용적인 한계선이 빠르게 앞당겨지고 있다는 신호예요. 모바일 앱을 만들고 있다면 슬쩍 테스트해볼 만한 시점이에요.

1994년 마이크로소프트 인턴 면접 문제, 지금 봐도 의미 있을까요

• 저자는 1994년 MS 인턴 면접에서 네 명의 면접관에게 각각 하나씩 질문을 받았어요. 첫 번째는 C로 버퍼 간 직사각형 영역을 복사하는 코드를 짜는 것, 두 번째는 null 종료 ASCII-Z 문자열 복사였어요.
• 질문들은 난이도 순으로 설계되었고, 적어도 두 문제는 성능 최적화에 초점을 맞췄어요. 30년이 지난 지금도 저자가 네 문제를 모두 기억하고 있다는 게 인상적이에요.
• 당시 면접 문화가 지금의 코딩 테스트 문화의 원형이기도 해요. 로우레벨 메모리 조작, 문자열 처리, 성능 최적화라는 주제는 시대를 막론하고 반복되는 단골 소재죠.

💡 오늘의 인사이트

요즘 코딩 면접 준비를 하다 보면 알고리즘 문제 풀이에만 집중하게 되는데, 이 글을 보면 30년 전에도 결국 묻는 건 비슷했어요. 메모리를 어떻게 다루는지, 성능을 어떻게 생각하는지. 유행하는 풀이법 암기보다 기본 원리를 깊이 이해하는 쪽이 훨씬 오래가는 경쟁력이에요.
