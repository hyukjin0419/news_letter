OpenAI가 보안 취약점 찾는 CLI 도구를 오픈소스로 풀었어요

• OpenAI가 공개한 @openai/codex-security는 코드 저장소를 스캔해서 보안 취약점을 찾고, 고치는 것까지 도와주는 CLI이자 TypeScript SDK예요. Node.js 22+와 Python 3.10+ 환경이면 바로 쓸 수 있어요.
• ChatGPT 계정이나 OpenAI API 키로 인증하면 되고, 스캔 이력은 로컬 워크벤치 디렉토리에 저장돼요. PR 올리기 전에 변경사항만 골라서 리뷰하는 것도 가능해요.
• 환경변수 설정만으로 CI/CD 파이프라인에 붙일 수 있어요. GitHub Actions 같은 곳에 끼워 넣으면, 보안 검토를 자동화할 수 있는 거죠.

💡 오늘의 인사이트

보안 코드 리뷰, 솔직히 매번 꼼꼼하게 하기가 쉽지 않죠. 놓치면 나중에 더 크게 터지는 게 보안인데, 이런 도구를 파이프라인에 하나 끼워두는 것만으로도 안전망이 하나 더 생기는 거예요. 완벽한 대체제는 아니지만, 사람이 놓치기 쉬운 패턴을 잡아주는 보조 도구로는 충분히 써볼 만해요. 다음 스프린트에 사이드 태스크로 붙여보는 건 어떨까요.

바다가 숨을 잃어가고 있어요, 그리고 이건 우리 이야기예요

• UC 샌디에이고 스크립스 해양연구소 연구팀이 발표한 논문에 따르면, 지구 바다와 수중 생태계에서 산소가 빠르게 줄어드는 현상이 지구 안정성을 위협하는 핵심 요인으로 떠오르고 있어요. 원인은 인간이 만든 온난화, 과잉 영양 오염, 수중 순환 변화예요.
• 산소 감소는 단독으로 작동하지 않아요. 기후변화, 해양 산성화, 생물 다양성 손실 같은 다른 위기들과 맞물려서 서로를 악화시키는 구조예요. 연구팀은 이를 지구 경계 프레임워크의 열 번째 경계로 추가할 것을 제안했어요.
• 미생물부터 상어까지, 수중 생태계 전반이 영향을 받고 있어요. 연구팀은 이 변화가 인간의 시간 척도에서 되돌리기 어려운 수준으로 진행될 수 있다고 경고해요.

💡 오늘의 인사이트

28년 만에 Half-Life가 Mac OS 9에서 돌아가요, 진짜로요

• GitHub 사용자 doctashay가 Xash3D FWGS 엔진 포크를 이용해 Half-Life를 PowerPC 맥에 포팅했어요. Mac OS 9.0 이상이면 G3, G4 프로세서에서 처음부터 끝까지 완주 가능하고, 멀티플레이어도 돼요.
• Half-Life, Blue Shift, Opposing Force, Uplink 데모까지 포함돼 있어요. 다만 VRAM이 8MB 미만인 기기에서는 성능이 떨어질 수 있어요. 1999년 기준으로도 빠듯한 스펙이죠.
• 밸브는 1999년에 Mac OS 9 버전을 출시하려다 취소했고, Mac 버전은 2013년에야 인텔 기반으로 나왔어요. 이번 포팅은 그 24년 묵은 숙제를 커뮤니티가 해결한 거예요.

💡 오늘의 인사이트

이 프로젝트가 멋진 건 단순히 옛날 게임을 돌려서가 아니에요. 공식 지원이 끊긴 플랫폼에서, 오픈소스 엔진을 포크해서, 혼자 끝까지 해냈다는 거잖아요. 우리가 레거시 시스템 앞에서 '이건 너무 오래됐어'라고 포기할 때, 누군가는 28년 된 코드를 들고 끝까지 파고드는 거예요. 오늘 손대기 싫었던 그 레거시 코드, 조금 다르게 보이지 않나요.
