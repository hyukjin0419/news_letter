975B짜리 오픈 모델이 나왔는데, 실제로 쓸 수 있을까요?

• Inkling은 975B 파라미터 규모의 Mixture-of-Experts 모델이에요. 하지만 실제로 활성화되는 파라미터는 41B라서, 생각보다 훨씬 현실적인 비용으로 돌릴 수 있어요. 작은 버전인 Inkling-Small은 12B 활성 파라미터로 더 가볍게 쓸 수 있고요.
• 텍스트, 이미지, 오디오를 한 번에 처리하고 최대 1M 토큰 컨텍스트를 지원해요. 긴 코드베이스나 문서를 통째로 넣어도 된다는 뜻이죠. TogetherAI, Fireworks, Databricks 같은 파트너 API로 바로 붙일 수 있어요.
• 파인튜닝은 Tinker 플랫폼에서, 추론은 vLLM이나 llama.cpp로 직접 돌릴 수 있어요. 웹 개발, 툴 호출, 코드 생성 같은 에이전틱 작업도 공식적으로 지원한다고 하니, 사이드 프로젝트에 붙여볼 만해요.

💡 오늘의 인사이트

오픈 웨이트 모델이 나올 때마다 '이번엔 진짜 써볼 수 있나?' 싶죠. Inkling은 Hugging Face에 올라와 있고 추론 프레임워크도 익숙한 것들이라 진입 장벽이 낮아요. 단, 리스크 문서가 거의 없다는 점은 프로덕션 도입 전에 꼭 직접 검증해보세요. 좋은 모델일수록 한계를 직접 찾아보는 게 맞아요.

WAVE 02 178 pts · 198 comments

터미널에서 AI가 코드를 짜준다고요? Grok Build가 오픈소스가 됐어요

• xAI가 만든 터미널 기반 AI 코딩 에이전트 Grok Build가 오픈소스로 공개됐어요. Rust로 작성된 풀스크린 TUI인데, 코드베이스 파악, 파일 편집, 셸 명령 실행까지 혼자 다 해요.
• 쓰는 방법이 세 가지예요. 직접 터미널에서 대화하거나, headless 모드로 CI 파이프라인에 넣거나, Agent Client Protocol(ACP)로 에디터에 임베드할 수 있어요. macOS, Linux, Windows 모두 사전 빌드 바이너리를 제공해요.
• 소스 코드는 TUI, 에이전트 런타임, 툴 구현체, 워크스페이스 관리 등 모듈형 크레이트로 나뉘어 있어요. 직접 빌드하려면 Rust 툴체인과 protoc만 있으면 돼요.

💡 오늘의 인사이트

외부 기여는 받지 않는다고 명시돼 있어요. xAI 내부 모노레포에서 주기적으로 싱크하는 구조라서요. 그래도 코드를 읽는 것만으로도 배울 게 많아요. Rust로 TUI 에이전트를 어떻게 설계했는지, ACP 같은 프로토콜을 어떻게 붙였는지 살펴보면 내 프로젝트 구조를 다시 생각해보게 되거든요. Windows 빌드는 아직 검증이 덜 됐다고 하니 윈도우 쓰시는 분들은 조금 기다리는 게 편해요.

브라우저 안에서 Firefox가 돌아간다는 게 무슨 말이에요?

• Firefox의 핵심 엔진인 Gecko를 WebAssembly로 컴파일해서, 브라우저 탭 하나 안에서 Firefox 전체 UI가 실행돼요. 브라우저 속에 브라우저가 있는 거예요.
• 웹 콘텐츠는 Puter가 호스팅하는 Wisp 서버를 통해 프록시돼요. 실제 웹을 탐색할 수 있고, 시작 로그와 고급 옵션도 있어요.
• 실용적인 도구라기보다는 WebAssembly의 가능성을 보여주는 실험에 가까워요. 하지만 성능이나 보안 제약 같은 한계는 아직 공개된 내용이 없어요.

💡 오늘의 인사이트

처음엔 '이게 뭐에 쓰이지?' 싶을 수 있어요. 그런데 Gecko를 WebAssembly로 포팅했다는 것 자체가 대단한 일이에요. 렌더링 엔진 같은 거대한 C++ 코드베이스를 Wasm으로 옮기는 게 어떤 과정인지 궁금하다면, 이 프로젝트를 파고드는 게 좋은 공부가 돼요. 당장 프로덕션에 쓸 건 아니지만, Wasm이 어디까지 갈 수 있는지 감을 잡는 데는 이만한 예시가 없어요.
