75,000권 무료 전자책, 개발자가 놓치고 있는 보물창고

• Project Gutenberg는 1971년부터 운영된 무료 전자책 라이브러리예요. 회원가입도, 결제도 없이 EPUB과 Kindle 형식으로 바로 다운로드할 수 있어요.
• 저작권이 만료된 고전 문학 75,000권 이상이 있고, 브라우저에서 바로 읽거나 LibriVox 오디오북으로도 들을 수 있죠.
• 50년 넘게 자원봉사자들이 직접 교정하고 오류를 제보하며 유지해온 프로젝트예요. 오픈소스 커뮤니티의 정신이 그대로 담겨 있어요.

💡 오늘의 인사이트

기술 문서만 읽다 보면 어느 순간 글쓰기 감각이 무뎌지는 느낌, 다들 받아본 적 있죠? 고전 문학은 생각보다 훌륭한 글쓰기 교과서예요. 커밋 메시지 하나, PR 설명 한 줄도 결국 글이니까요. 출퇴근길 15분, 책 한 챕터로 시작해보는 건 어떨까요.

WAVE 02 116 pts · 41 comments

닌텐도 64에서 윈도우가 부팅된다, 이게 말이 되는 일인가요

• 취미 프로젝트로 Windows CE 2.11을 닌텐도 64에서 실제로 부팅하는 데 성공했어요. VR4300 MIPS 프로세서 위에서 커스텀 HAL과 디바이스 드라이버를 직접 만들었죠.
• N64 컨트롤러가 마우스 역할을 해요. A 버튼이 왼쪽 클릭, B 버튼이 오른쪽 클릭이에요. FatFS 기반 SD카드를 파일 브라우저에서 탐색할 수도 있어요.
• 소스코드는 MIT 라이선스지만, 빌드 결과물에 Microsoft의 CE 2.11 SDK 바이너리가 포함돼서 재배포는 EULA 위반이에요. 빌드하려면 SDK를 직접 구해야 해요.

💡 오늘의 인사이트

이런 프로젝트를 보면 '저게 무슨 의미가 있지?'라는 생각이 먼저 들 수도 있어요. 그런데 HAL을 처음부터 짜고, 없는 드라이버를 만들고, 낯선 아키텍처와 씨름하는 과정이 결국 시스템을 깊이 이해하는 가장 빠른 길이에요. 실용적인 프로젝트만 하다 보면 놓치는 감각이 있거든요. 가끔은 쓸모없어 보이는 것에서 가장 많이 배워요.

WAVE 03 166 pts · 44 comments

Zulip이 재단이 됐어요, 슬랙 대안 중 가장 진지한 행보

• Zulip의 창업자 Tim Abbott와 핵심 팀원들이 Anthropic으로 이직하면서, 회사 Kandra Labs를 비영리 재단에 기부했어요. 거버넌스 구조는 Mozilla, Signal, Wikipedia를 참고했죠.
• Zulip의 가장 큰 특징은 topic-based threading 모델이에요. 채널 안에서 대화가 주제별로 분리되기 때문에 비동기 소통이 많은 오픈소스 커뮤니티에서 특히 인기가 높아요.
• 최근 Zulip 12.0은 160명의 기여자가 5,500개의 커밋을 쌓아 만들었어요. 창업자가 떠나도 프로젝트가 흔들리지 않을 만큼 커뮤니티가 탄탄해요.

💡 오늘의 인사이트

팀 채팅 도구 하나가 조직 문화를 얼마나 바꾸는지, 써보기 전엔 잘 몰라요. Slack의 채널 방식이 익숙하다면 Zulip의 topic 구조가 처음엔 낯설 수 있어요. 그런데 비동기로 일하는 팀이라면 한번 진지하게 고려해볼 만해요. 대화가 흘러가지 않고 맥락이 남는다는 게 생각보다 큰 차이거든요.
