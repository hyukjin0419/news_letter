토크나이저가 1000배 빨라졌다고요? 진짜입니다

• Rust로 만든 GigaToken은 HuggingFace tokenizers보다 최대 1,268배 빠른 토크나이징 속도를 냅니다. 130조 토큰 규모의 Common Crawl 전체를 약 6.5시간 만에 처리할 수 있어요. 기존에 며칠씩 걸리던 전처리 파이프라인을 하루 안에 끝낼 수 있다는 뜻이죠.
• 기존 코드를 거의 안 바꿔도 됩니다. HuggingFace와 Tiktoken API와 호환되는 드롭인 방식이라, import 한 줄만 바꿔도 바로 적용할 수 있어요. GPT-2, Llama, DeepSeek, Qwen 등 25가지 이상의 토크나이저를 지원하고요.
• 속도의 비결은 SIMD 명령어셋(AVX512, AVX2, NEON)을 활용한 사전 토크나이징과 파이썬 호출 오버헤드 최소화예요. 단, SentencePiece는 아직 최적화가 덜 됐고 WordPiece는 미지원이니, 사용 전에 자신의 모델이 어떤 토크나이저를 쓰는지 먼저 확인해 보세요.

💡 오늘의 인사이트

LLM 학습이나 데이터 전처리 파이프라인을 운영 중이라면, 토크나이징 단계가 생각보다 큰 병목일 수 있어요. GPU는 놀고 CPU만 바쁜 상황, 한 번쯤 겪어보셨죠? GigaToken은 코드 변경 없이 바로 벤치마크를 돌려볼 수 있으니, 지금 당장 프로파일러 켜기 전에 이것부터 교체해 보는 것도 좋은 선택이에요.

WAVE 02 51 pts · 7 comments

하루 만에 나만의 GitHub 이슈 관리 도구를 만든 사람의 이야기

• 개발자 Charles Choi는 GitHub 이슈를 Emacs Org 파일로 매번 손으로 복사하고 있었어요. 그걸 자동화하기 위해 GitHub 전용 클라이언트를 새로 만드는 대신, gh CLI에 인증을 맡기고 Elisp 20줄로 이슈 목록을 불러오는 방식을 택했습니다. 하루 만에 완성했고요.
• 핵심 아이디어는 '다 직접 만들지 않는 것'이에요. Transient 패키지로 UI를, vtable로 테이블 렌더링을, Pandoc으로 마크다운 변환을 각각 기존 도구에 위임했어요. 바퀴를 다시 발명하지 않고, 있는 바퀴를 조합한 거죠.
• 이 글이 말하는 '유연한 컴퓨팅(malleable computing)'의 핵심은 재시작 없이 실행 중인 환경에서 바로 코드를 수정하고 확인할 수 있다는 점이에요. Emacs가 오래된 도구임에도 여전히 개발자들 사이에서 살아있는 이유 중 하나예요.

💡 오늘의 인사이트

반복 작업을 발견했을 때 '나중에 자동화해야지'라고 미루는 게 익숙하죠. 이 사람은 완벽한 도구를 목표로 삼지 않고, 오늘의 불편함을 오늘 해결했어요. 거창한 설계 없이 기존 CLI와 패키지를 조합해서요. 여러분의 일상에도 20줄로 해결될 수 있는 반복 작업이 숨어 있을지 몰라요.

Safari도 조용히 업데이트됐어요. 프론트엔드 개발자라면 알아두세요

• Safari Technology Preview 248에서 TC39의 BigInt Math 제안이 구현됐어요. BigInt.pow(), BigInt.sqrt() 같은 메서드를 이제 Safari에서도 쓸 수 있게 됩니다. 금융 계산이나 암호화 관련 로직에서 큰 수를 다루는 분들은 눈여겨볼 만해요.
• CSS 쪽에서는 progress() 함수에 no-clamp 옵션이 추가됐고, 유사 색상 공간 간 색상 컴포넌트 전달 기능도 들어왔어요. 그리드 크기 계산, 뷰 전환, 미디어 쿼리 관련 렌더링 버그도 여러 건 수정됐으니 크로스 브라우저 이슈로 고생하셨던 분들은 한번 확인해 보세요.
• 접근성 개선도 있었어요. hidden='until-found' 속성을 사용하는 공개 위젯에서 VoiceOver 내비게이션이 제대로 동작하지 않던 문제가 수정됐어요. WebDriver에서 Digital Credentials API도 지원하기 시작했고요.

💡 오늘의 인사이트

Safari 업데이트는 크롬이나 파이어폭스에 비해 조용히 넘어가기 쉬운데, iOS 사용자 비율이 높은 서비스를 운영한다면 꼭 챙겨야 해요. Technology Preview는 정식 배포 전에 미리 테스트할 수 있는 좋은 기회예요. 지금 Safari에서만 이상하게 보이는 UI가 있다면, 이번 릴리스 노트에 힌트가 있을 수도 있어요.
