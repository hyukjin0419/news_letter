집 설계도를 VR로 걸어다녀 봤더니, 2D PDF가 얼마나 거짓말이었는지 알았어요

• 건축가한테 받은 도면을 Fusion 360으로 3D 모델로 변환하고, USDZ 파일로 내보내면 Apple Vision Pro에서 실제 공간처럼 걸어다닐 수 있어요. AI 도움이나 Fiverr 외주로도 변환이 가능하니 3D 툴 못 다뤄도 괜찮아요.
• 빈 와이어프레임만 보면 공간감이 안 잡히는데, IKEA가 제공하는 공식 3D 가구 모델을 배치하고 Poly Haven으로 스카이박스까지 입히면 '이 방이 실제로 얼마나 좁은지'를 몸으로 느낄 수 있어요.
• 건축가가 직접 만들어준 3D 워크스루보다 Vision Pro 체험이 공간 이해에 훨씬 효과적이었다는 게 핵심이에요. 고해상도 디스플레이와 공간 센서 덕분에 다른 VR 기기 대비 스케일 감각이 훨씬 정확하게 전달돼요.

💡 오늘의 인사이트

이 사례, 집 살 때만 쓸 이야기가 아니에요. 사무실 리모델링 검토, 데이터센터 랙 배치, 심지어 신규 입사자 온보딩용 오피스 투어까지 응용할 수 있어요. 팀에 Vision Pro 한 대만 있다면, 기획 단계에서 '이거 생각이랑 다른데요'라는 말이 훨씬 줄어들 거예요. 도면 PDF 돌려보며 회의하는 시간이 얼마나 비효율적인지, 한 번 써보면 바로 알게 되죠.

맥북 에어에서 260억 파라미터 AI 모델을 2GB RAM으로 돌린다고요?

• TurboFieldfare는 Swift 6.2와 Metal 4로 만든 오픈소스 런타임이에요. Gemma 4 26B-A4B 모델 전체를 메모리에 올리는 대신, 핵심 1.35GB만 RAM에 두고 나머지 전문가 가중치는 SSD에서 필요할 때마다 스트리밍해서 읽어요. 덕분에 8GB RAM 맥에서도 실행이 돼요.
• 성능은 M2 맥북 에어 기준 초당 5~6토큰, M5 Pro에서는 초당 31~35토큰이에요. 네이티브 맥 앱, CLI, 그리고 OpenAI 호환 로컬 서버까지 지원하니 기존 코드베이스에 붙이기도 어렵지 않아요.
• 단, 현재는 텍스트 전용이고 이미지나 오디오는 안 돼요. macOS 26과 Metal 4가 필수라 구형 맥은 지원 안 하고, 로컬 서버엔 인증이나 TLS가 없어서 외부에 절대 열면 안 돼요.

💡 오늘의 인사이트

클라우드 API 비용이 부담스럽거나, 코드나 사내 문서처럼 외부로 못 보내는 데이터를 다뤄야 할 때 이런 로컬 추론 엔진이 진짜 빛을 발해요. 103가지 최적화 실험 결과를 문서로 공개했다는 것도 눈여겨볼 만해요. 단순히 '돌아간다'가 아니라 왜 이 선택을 했는지 근거가 있는 프로젝트예요. macOS 26 베타 올려둔 맥이 있다면 오늘 한 번 클론해볼 만한 레포예요.

WAVE 03 469 pts · 295 comments

터미널 멀티플렉서를 다시 만든다고요? Terraform 만든 사람이요?

• Superlogical은 Terraform과 Vagrant 창시자인 Mitchell Hashimoto가 공동 창업한 회사예요. 개발자 작업이 인터랙티브, 자동화, 프로덕션 환경으로 쪼개져 있는 문제를 하나의 플랫폼으로 묶겠다는 비전이에요.
• 시작은 터미널 멀티플렉서예요. 웹 브라우저와 macOS, iOS 네이티브 앱 모두 지원하고, 라이브 세션 공유가 기본 내장돼 있어요. tmux에서 늘 불편했던 스크롤백과 텍스트 선택도 네이티브 수준으로 개선했다고 해요.
• 터미널 멀티플렉서는 3단계 로드맵의 1단계일 뿐이에요. 장기적으로는 여러 앱과 환경에 걸친 작업을 조합하고 프로덕션에서도 안전하게 쓸 수 있는 기반 시스템을 만드는 게 목표예요. 지금 베타 신청을 받고 있어요.

💡 오늘의 인사이트

솔직히 터미널 멀티플렉서 시장에 새 플레이어가 나온다고 하면 '또?'라는 생각이 먼저 들죠. 그런데 이 팀이 Vercel, Heroku 출신 디자이너까지 데려왔다는 건 UX를 진심으로 고민하고 있다는 신호예요. tmux를 쓰면서 '이거 왜 이렇게 불편하지' 싶었던 순간이 한 번이라도 있었다면, 베타 신청 해두는 게 손해는 아니에요. 나중에 팀 온보딩 도구로 쓸 수 있을지도 모르니까요.
