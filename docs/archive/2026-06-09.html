OpenAI, 상장 신청서를 SEC에 냈습니다. 그런데 언제 상장할지는 모른다고요?

• OpenAI가 SEC에 S-1 초안을 비공개로 제출했어요. IPO를 향한 첫 공식 발걸음이지만, 정작 회사는 "상장 시점은 미정"이라고 선을 그었죠.
• 흥미로운 건 이유예요. "비상장 상태일 때 더 잘할 수 있는 일들이 있다"는 게 OpenAI의 입장이에요. 주주 눈치 없이 장기 베팅을 이어가겠다는 뜻으로 읽혀요.
• 이번 발표는 SEC Rule 135를 준수한 공식 공지예요. 증권 판매 제안이 아니라는 점도 명시했고요. 시장에 신호는 보내되, 약속은 하지 않는 영리한 행보예요.

💡 오늘의 인사이트

OpenAI의 이번 행보는 개발자 입장에서도 꽤 의미 있어요. 상장하면 분기 실적 압박이 생기고, 그게 API 가격이나 모델 공개 정책에 영향을 줄 수 있거든요. 지금처럼 과감한 실험을 이어갈 수 있는 건 사실 비상장 덕분이기도 해요. OpenAI가 언제 상장하느냐보다, 상장 이후에도 지금의 개발자 친화적인 태도를 유지할 수 있을지가 진짜 관전 포인트예요.

새 Siri가 옵니다. 이번엔 진짜 달라질까요?

• Apple이 Apple Intelligence와 함께 완전히 새로워진 Siri AI를 올해 안에 출시한다고 발표했어요. 일단 영어부터 시작이고, 한국어 지원 일정은 아직 미정이에요.
• 이번 Siri의 핵심 키워드는 두 가지예요. 프라이버시와 맥락 이해. 내 앱 사용 패턴과 상황을 파악해서 더 자연스럽게 도와주는 방향으로 설계됐다고 해요.
• 개발자 입장에서 주목할 건 앱 통합이에요. Siri가 서드파티 앱의 기능을 직접 실행할 수 있게 되면, App Intents 같은 API 대응이 점점 중요해질 거예요.

💡 오늘의 인사이트

솔직히 Siri는 오랫동안 개발자들 사이에서 "왜 이렇게 못하지?"의 대명사였죠. Apple이 이번엔 진지하게 바꾸려는 것 같아요. iOS 앱을 만들고 있다면, Siri와 연동되는 기능을 미리 고민해두는 게 좋을 것 같아요. 나중에 급하게 붙이는 것보다 처음부터 설계에 녹여두는 게 훨씬 자연스럽거든요.

WAVE 03 470 pts · 316 comments

1조 개 파라미터 모델이 초당 1000 토큰을 뽑아냅니다

• 샤오미가 MiMo-V2.5-Pro-UltraSpeed를 공개했어요. 1조 파라미터짜리 모델에서 초당 1000 토큰 이상의 속도를 세계 최초로 달성했다고 해요. 핵심 기술은 자체 개발한 추론 런타임 TileRT예요.
• 가격은 기존 MiMo-V2.5-Pro의 3배지만, 속도는 약 10배 빨라요. 퀀트 트레이딩, 사기 탐지, 의료 영상 분석처럼 실시간 판단이 필요한 영역에서 의미 있는 선택지가 될 수 있어요. 같은 시간 안에 Best-of-N 같은 병렬 추론 전략도 쓸 수 있고요.
• 다만 접근이 쉽지는 않아요. 6월 9일부터 23일까지 2주간 한정 체험인데, 기업과 전문 개발자 대상 신청제로 운영돼요. 하루 큐 10개, 세션 30분 제한도 있고요.

💡 오늘의 인사이트

"빠른 모델"이라고 하면 보통 작은 모델을 떠올리죠. 그런데 1조 파라미터에서 이 속도가 나온다는 건 추론 인프라 자체가 한 단계 올라갔다는 신호예요. 지금 당장 쓸 수 없더라도 이 방향은 기억해둘 만해요. 실시간 응답이 필요한 서비스를 설계하고 있다면, 6개월 뒤의 인프라 비용과 지연 시간을 지금과 다르게 가정해도 될 것 같거든요.
