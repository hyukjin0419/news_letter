광고 없는 검색엔진, 저시력 개발자가 6개월 써보고 내린 결론

• Kagi는 광고와 SEO 스팸 없이 구독료로 운영돼요. 월 10달러짜리 Professional 플랜이면 무제한 검색이 가능하고, 결과가 광고주가 아닌 품질 기준으로 정렬돼요.
• 저시력 사용자 입장에서 가장 큰 차이는 '화면 피로도'였어요. 자동재생 콘텐츠, 배너 광고, AI 요약 박스가 없으니 눈이 덜 피로하다는 거죠. 개발자라면 검색 결과 훑는 시간이 얼마나 긴지 알잖아요.
• Lenses 기능으로 Forums, Academic, Programming 같은 필터를 저장해두면, 스택오버플로우 스타일 결과만 골라서 볼 수 있어요. 매번 site: 연산자 쓰는 수고를 덜어줘요.

💡 오늘의 인사이트

검색엔진을 바꾸는 건 생각보다 큰 결정이에요. 하지만 하루에 수십 번 검색하는 개발자한테 '광고 없는 깔끔한 결과'가 주는 집중력 차이는 꽤 실질적이에요. 무료 체험 100회 제공하니까, 다음 번 디버깅 세션 때 한번 써보는 것도 나쁘지 않아요.

WAVE 02 129 pts · 77 comments

4년 동안 재부팅 한 번 없던 서버, 드디어 이사했습니다

• 운영 중인 서버가 Ubuntu 16.04 LTS라면, 이미 5년 넘게 보안 업데이트가 끊긴 상태예요. 이 글의 주인공도 1491일 업타임을 자랑하다가, 결국 FreeBSD로 이전했어요.
• 이사 결과가 꽤 인상적이에요. 월 비용은 13달러에서 6유로로 절반 이하로 줄었고, RAM과 CPU는 두 배, 트래픽 허용량은 10배가 됐어요. Hetzner로 옮기면서 Bastille Jails로 컨테이너화까지 챙겼고요.
• 정적 사이트를 nginx와 Hugo로 서빙하는 구조는 그대로 유지했어요. 기술 스택을 통째로 바꾸지 않고, OS와 호스팅만 교체한 거라 마이그레이션 부담이 생각보다 작았다고 해요.

💡 오늘의 인사이트

아무 일도 안 일어났다고 해서 안전한 건 아니에요. 지원 종료된 OS 위에서 서비스가 돌아가고 있다면, 지금 당장 문제가 없더라도 언제 터질지 모르는 시한폭탄이에요. 이 글이 '나도 한번 점검해봐야겠다'는 계기가 됐으면 해요.

WAVE 03 163 pts · 76 comments

서버도 없고, 클라우드 비용도 없는 앱 배포가 가능할까요

• Freenet은 중앙 서버 없이 브라우저에서 돌아가는 탈중앙화 앱 플랫폼이에요. 사용자가 앱을 실행하면 그 자체가 네트워크의 일부가 되고, 누군가 서버를 꺼도 앱이 내려가지 않아요.
• 개발자 입장에서 흥미로운 건 스택이에요. Rust와 TypeScript로 개발하고, 피어 네트워크에 배포하면 끝이에요. AWS 콘솔 열 필요도, 도메인 설정할 필요도 없어요. 유지보수 비용이 사실상 0이에요.
• 네트워크 구조는 소규모 세계 링 구조로, 메시지가 몇 번의 홉만으로 목적지에 도달해요. 이론적으로는 확장성도 사용자가 늘수록 자연스럽게 올라가는 구조예요.

💡 오늘의 인사이트

아직 프로덕션에 쓰기엔 검증이 부족하고, 보안이나 확장성에 대한 실전 데이터도 많지 않아요. 하지만 '서버 없는 배포'라는 개념 자체는 충분히 흥미로워요. 사이드 프로젝트나 검열 걱정 없는 커뮤니케이션 도구를 만들어보고 싶다면, 한번 들여다볼 만한 프로젝트예요.
