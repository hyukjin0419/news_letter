2000년 전 불탄 두루마리를 X선과 머신러닝으로 읽어냈어요

• 79년 베수비오 화산 폭발로 탄화된 헤르쿨라네움 파피루스 두루마리 PHerc. 1667을, 물리적으로 펼치지 않고 처음으로 완전히 해독했어요. 고해상도 X선 단층촬영과 머신러닝으로 내부 층을 3D 재구성해서 기원전 2세기 스토아 철학 문헌을 복원했죠.
• 핵심 기술 스택은 phase-contrast X-ray microtomography와 3D segmentation, 그리고 machine learning이에요. 유럽 싱크로트론 방사광 시설(ESRF BM18 빔라인)에서 촬영한 데이터를 기반으로, 추가로 두 개의 두루마리도 부분 해독에 성공했어요.
• 방법론과 코드, 데이터가 모두 오픈소스로 공개됐어요. 아직 봉인된 수백 개의 두루마리를 같은 방식으로 읽을 수 있는 확장 가능한 파이프라인이 만들어진 거예요.

💡 오늘의 인사이트

비파괴 스캔 데이터에서 숨겨진 구조를 복원하는 이 접근법, 사실 우리 업무랑 꽤 닮아 있어요. 레거시 시스템의 문서화되지 않은 내부 로직을 역추적할 때, 직접 뜯어보는 대신 로그와 트레이스 데이터로 3D 그림을 그리는 것처럼요. '건드리지 않고 이해한다'는 원칙, 프로덕션 디버깅에서도 꽤 중요한 덕목이죠.

WAVE 02 243 pts · 98 comments

나이 확인한다고 ID 내놓으라는 인터넷, 진짜 괜찮은 걸까요

• 호주가 2025년 12월부터 만 16세 미만의 소셜미디어 사용을 금지하면서, 플랫폼들이 biometric data나 정부 발급 신분증을 제3자 인증 업체에 제출하도록 요구하고 있어요. 문제는 이 업체들이 다른 나라에 있고, 데이터 보호 기준이 불명확하다는 거예요.
• 실효성도 의심스러워요. 연구에 따르면 대상 아동의 약 70%가 여전히 소셜미디어를 쓰고 있어요. 프라이버시 비용은 치르면서 목표는 달성 못 하는 상황이죠. 법 시행 전 조사에서도 서비스 제공업체들이 필요 이상으로 데이터를 오래 보관하는 경향이 확인됐어요.
• 호주 법은 인증 목적 달성 후 데이터를 파기하도록 규정하지만, '목적'의 정의가 모호해서 민원이나 이의제기 기간 동안은 보관이 허용될 수 있어요. third-party verification 업체가 외국 정부의 데이터 요청에 응할 가능성도 배제할 수 없고요.

💡 오늘의 인사이트

서비스에 나이 인증이나 본인 확인 기능을 붙일 때, '우리는 그냥 SDK 붙이면 끝'이라고 생각하기 쉬워요. 그런데 그 SDK 뒤에서 누가 어떤 데이터를 얼마나 오래 갖고 있는지, 우리 서비스 약관에 명시는 됐는지 한 번쯤 따져볼 필요가 있어요. 규제 준수는 법무팀 일이고 개발자는 구현만 하면 된다는 생각, 이제는 조금 바꿔야 할 때인 것 같아요.

GPU 없이 이미지를 만드는 AI, 전력 소비를 1000분의 1로 줄인다고요

• Un-0은 트랜스포머나 일반 딥러닝 대신, 물리적 진동자 시스템인 coupled oscillators의 시뮬레이션으로 이미지를 생성해요. ImageNet 64x64 기준 FID 6.74를 달성해서, 초기 발표 당시 주요 이미지 생성 모델들과 비슷한 수준의 품질을 보여줬어요.
• 목표는 GPU 기반 AI 대비 약 1000배의 에너지 효율이에요. AI 인프라 전기 요금이 심각한 고민거리가 된 요즘, 물리 기반 컴퓨팅이 하나의 대안으로 주목받기 시작한 거죠.
• 모델 가중치, 학습 코드, 실험 코드 전부 오픈소스로 공개됐어요. 아직 큰 벤치마크나 실제 서비스 환경에서의 확장성은 검증이 필요한 초기 단계지만, 재현하고 실험해볼 수 있는 환경은 갖춰져 있어요.

💡 오늘의 인사이트

당장 프로덕션에 쓸 기술은 아니에요. 그런데 'AI는 곧 GPU'라는 공식이 흔들리기 시작하는 신호탄으로 봐두면 좋겠어요. 클라우드 AI 비용이 점점 부담스러워지는 지금, 에너지 효율 중심의 새로운 컴퓨팅 패러다임이 어떻게 발전하는지 관심 가져두면, 2~3년 뒤 아키텍처 결정할 때 시야가 달라질 수 있어요.
