Git이 게임 개발자들한테 욕먹는 이유, 에픽게임즈가 직접 해결했어요

• 에픽게임즈가 오픈소스로 공개한 Lore는 대용량 바이너리 파일에 최적화된 중앙집중식 버전 관리 시스템이에요. 게임 에셋처럼 수십 GB짜리 파일을 다루는 팀이라면 Git의 한계를 뼈저리게 느껴봤을 텐데, 바로 그 문제를 정면으로 겨냥했죠.
• 저장소 상태를 Merkle tree 구조로 표현하고, 콘텐츠 기반 주소 지정 방식으로 중복 데이터를 자동으로 제거해요. 변경 이력은 불변 체인으로 관리되니까 히스토리가 오염될 걱정도 없어요.
• 가장 실용적인 기능은 sparse hydration이에요. 저장소 전체를 내려받지 않고 지금 당장 필요한 파일만 골라서 가져올 수 있어요. 수백 GB짜리 모노레포에서 일하는 팀이라면 출근 첫 번째 git pull에 커피 두 잔이 필요했던 기억, 이제 안녕이에요.

💡 오늘의 인사이트

솔직히 Git은 텍스트 코드 관리에는 여전히 최고예요. 근데 언리얼 엔진 프로젝트나 머신러닝 모델 파일처럼 바이너리가 주인공인 저장소에서는 Git LFS로 땜질하다가 결국 팀 전체가 고통받는 경우가 많죠. Lore가 당장 우리 팀 도구를 교체할 수준인지는 더 지켜봐야겠지만, 설계 철학 자체는 읽어볼 가치가 있어요. 특히 콘텐츠 기반 주소 지정과 희소 체크아웃 개념은 대용량 데이터 파이프라인 설계할 때도 응용할 수 있는 아이디어거든요.

오픈 가중치 AI 모델 경쟁, 이번엔 중국에서 판을 뒤집었어요

• Z.ai가 공개한 GLM-5.2가 Artificial Analysis 인텔리전스 인덱스 오픈 가중치 부문 1위에 올랐어요. 총 744B 파라미터에 40B만 활성화하는 MoE 구조인데, 전작 GLM-5.1 대비 인덱스 점수를 11점이나 올렸죠. 라이선스는 MIT예요.
• 컨텍스트 윈도우가 전작의 200K에서 1M 토큰으로 늘었어요. 긴 문서 분석이나 대규모 코드베이스를 통째로 넣어야 하는 작업에서 체감 차이가 클 거예요. 과학적 추론 벤치마크에서도 CritPt +16점, HLE +12점 등 의미 있는 향상을 보였어요.
• 비용은 입력 기준 100만 토큰당 $1.4로 꽤 합리적인 편이에요. 다만 태스크당 평균 출력 토큰이 43K로 경쟁 모델들보다 많아서, 실제 운영 비용은 단순 단가보다 높게 나올 수 있어요. 환각률도 28.1%로 프로덕션 투입 전에 충분한 검증이 필요해요.

💡 오늘의 인사이트

오픈 가중치 모델 생태계가 정말 빠르게 움직이고 있어요. 6개월 전만 해도 GPT 계열 API에 의존하는 게 당연했는데, 이제는 MIT 라이선스 모델로 사내 인프라를 구축하는 선택지가 현실적으로 가능해졌죠. 다만 벤치마크 점수와 실제 서비스 품질은 다른 얘기예요. 환각률 28%는 숫자로 보면 작아 보여도, 하루 1만 건 요청 처리하는 서비스에서는 2800건의 잠재적 오류예요. 새 모델 도입을 검토하고 있다면, 벤치마크보다 우리 서비스 도메인에 맞는 평가 세트를 직접 만들어서 테스트해보는 게 훨씬 믿음직해요.
