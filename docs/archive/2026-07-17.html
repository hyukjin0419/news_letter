오픈소스 모델이 드디어 3조 파라미터 시대를 열었어요

• Kimi K3는 2.8조 파라미터짜리 오픈소스 모델이에요. Mixture of Experts 구조와 Kimi Delta Attention을 써서 이전 버전보다 학습 효율을 2.5배 끌어올렸죠. 코딩, 추론, 지식 작업 모두 프론티어급 성능을 보여줘요.
• 특히 대규모 코드베이스 탐색과 터미널 도구 활용 능력이 인상적이에요. GPU 커널 최적화나 GPU 컴파일러 직접 구현 같은 작업도 소화한다고 하니, 인프라 쪽 작업에 써볼 만해요. 1-million-token 컨텍스트 창 덕분에 방대한 레포지토리도 한 번에 넣을 수 있어요.
• 다만 에이전트 환경에서 대화 히스토리를 제대로 유지하지 않으면 불안정해져요. 세션 도중에 다른 모델에서 K3로 갈아타는 것도 권장하지 않고요. 모델 가중치 전체 공개는 2026년 7월 27일 예정이에요.

내 코드와 문서, 밖으로 안 나가게 하면서 AI 쓸 수 있어요

• LM Studio Bionic은 코딩, 문서 작업, 리서치를 위한 에이전트 앱이에요. 로컬 모델, 클라우드 오픈소스 모델, 두 가지 방식을 유연하게 골라 쓸 수 있고, 클라우드를 써도 데이터를 보관하거나 학습에 활용하지 않아요.
• 코드베이스를 직접 불러와서 설명, 디버깅, 인라인 수정까지 해줘요. PDF나 스프레드시트 같은 문서도 샌드박스 환경에서 처리하고, 자동 체크포인트로 중간 결과를 저장해줘요. 음성 입력은 Voxtral로 로컬에서 바로 변환하니까 음성 데이터도 밖으로 안 나가요.
• 현재 GLM 5.2와 Kimi K2.7 Code 모델을 지원해요. 클라우드 모델을 쓰려면 계정 생성과 결제 설정이 필요한 건 감안해야 해요.

WAVE 03 465 pts · 103 comments

Comic Sans의 고향이 오픈소스로 풀렸어요, 진짜예요

• 마이크로소프트가 1996년에 만든 채팅 클라이언트 Comic Chat을 깃허브에 오픈소스로 공개했어요. IRC 대화를 실시간으로 만화 패널로 변환해주던 앱인데, 캐릭터 표정과 포즈, 말풍선 배치를 자연어 처리로 자동 생성했어요.
• Comic Sans 폰트가 처음 세상에 나온 곳이 바로 이 앱이에요. 타이포그래퍼 Vincent Connare가 1994년에 만들었고, Comic Chat에서 처음 쓰였죠. 기술 스택은 Visual C++ 4.0과 MFC, IRC 프로토콜이에요. SIGGRAPH 96에 논문으로도 발표된 프로젝트예요.
• 마이크로소프트는 소프트웨어 역사를 보존하고 개발자들이 코드를 탐구할 수 있도록 공개했다고 밝혔어요. 현재 Visual Studio 도구에 맞게 AI로 현대화를 시도한 결과물도 함께 포함되어 있어요.

💡 오늘의 인사이트

30년 전 코드가 지금 기준으로 얼마나 다를지 한번 들여다보는 것 자체가 꽤 재미있는 경험이에요. 레거시 코드를 현대 도구로 마이그레이션하는 게 얼마나 어려운 일인지, 이 프로젝트가 아주 솔직하게 보여주거든요. 오늘 내가 짜는 코드도 언젠가 누군가한테 이런 유물이 될 수 있다는 거, 가끔은 생각해볼 만해요.
