50만 줄 Ruby 코드를 며칠 만에 마이그레이션? Claude Fable 5가 바꾼 엔지니어링의 속도

• Anthropic이 Claude Fable 5를 공개했어요. 거의 모든 벤치마크에서 기존 모델을 앞서는 범용 모델인데, Stripe의 5천만 줄짜리 Ruby 코드베이스 마이그레이션에서 몇 달치 작업을 며칠로 압축했다고 해요. 소프트웨어 엔지니어링, 비전, 과학 연구 전반에서 성능이 뛰어나고, 가격은 입력 토큰 백만 개당 $10, 출력은 $50이에요.
• 민감한 요청은 자동으로 Claude Opus 4.8로 라우팅하는 안전장치가 있는데, 전체 세션의 5% 미만에서만 작동해요. 보수적으로 튜닝된 만큼 가끔 무해한 요청도 걸릴 수 있다는 점은 감안해야 해요.
• 사이버보안 전문가와 인프라 사업자를 위한 Claude Mythos 5도 별도로 출시됐어요. Project Glasswing을 통해 승인된 기관에만 제공되며, 안전장치가 해제된 버전이라 세계 최강 수준의 사이버 방어 능력을 갖췄다고 해요.

npm v12, 내년 여름에 출근했더니 빌드가 전부 깨져 있을 수도 있어요

• 2026년 7월로 예상되는 npm v12는 보안을 이유로 기본 동작을 세 가지 바꿔요. allowScripts가 기본 꺼짐으로 바뀌어서, 의존성 패키지의 preinstall, install, postinstall 스크립트가 명시적으로 허용하지 않으면 실행되지 않아요. node-gyp 빌드도 마찬가지예요.
• --allow-git과 --allow-remote도 기본값이 없음으로 바뀌어요. Git 저장소나 원격 URL로 직접 설치하던 의존성이 있다면 명시적으로 허용해야 해요. .npmrc 오버라이드를 통한 코드 실행 취약점을 막기 위한 조치예요.
• 지금 바로 npm 11.16.0 이상으로 올리고, npm approve-scripts --allow-scripts-pending으로 어떤 스크립트가 실행되고 있는지 먼저 확인해 보세요. 신뢰할 수 있는 패키지는 npm approve-scripts로 승인하면 package.json에 기록되니까 커밋해 두면 돼요.

💡 오늘의 인사이트

지금 당장 급하지 않다고 넘기기 쉬운 변경인데, 팀 프로젝트에 네이티브 모듈이나 Git 의존성이 하나라도 있다면 v12 업그레이드 순간 CI가 조용히 터질 수 있어요. 미리 확인하는 데 30분이면 충분해요. 내년 여름에 당황하지 않으려면 지금 스프린트에 짧게라도 넣어 두는 걸 추천해요.

마이크로초보다 빠른 AI 추론, GPU가 아니라 FPGA로 가능한 이유

• FPGA는 신경망을 소프트웨어 명령어가 아니라 디지털 회로 자체로 구현해요. 덕분에 GPU가 도저히 따라올 수 없는 마이크로초 이하의 응답 시간이 필요한 환경, 예를 들어 고빈도 거래나 실시간 제어 시스템에서 강점을 가져요.
• Kolmogorov-Arnold Networks, KAN은 기존 다층 퍼셉트론과 달리 단변량 함수 조합으로 모델을 구성해요. 이 구조가 FPGA의 LUT, 룩업 테이블 기반 연산과 잘 맞아서, 하드웨어 구현 효율이 크게 올라가요. 관련 논문이 FPGA 2026 최우수 논문과 ICML 2026에 각각 실렸어요.
• 실수를 고정소수점 양자화, fixed-point quantization로 비트열로 표현해서 FPGA에서 계산해요. 부동소수점을 쓰면 하드웨어 오버헤드가 너무 커지거든요. 양자화 오차를 얼마나 잘 제어하느냐가 학습 안정성의 핵심이에요.

💡 오늘의 인사이트

대부분의 서비스에서 GPU나 클라우드 추론으로 충분하지만, 밀리초도 아니고 마이크로초 단위 응답이 필요한 영역이 분명히 있어요. 금융, 로보틱스, 통신 쪽을 다루고 있다면 FPGA 기반 추론이 앞으로 중요한 선택지가 될 거예요. 지금 당장 쓸 기술이 아니더라도, 이런 접근이 존재한다는 걸 알아두면 나중에 아키텍처 결정할 때 분명히 도움이 돼요.
