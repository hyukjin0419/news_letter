내 차가 나를 팔고 있었다: RAV4에서 모뎀을 직접 뽑아낸 개발자 이야기

• 2024년 RAV4 하이브리드에는 DCM(Data Communication Module)이 탑재되어 있어요. 위치, 속도, 연료량, 심지어 운전자 주의 집중 데이터까지 수집해서 데이터 브로커에게 팔리고 있었죠. Subaru 원격 잠금 해제, Tesla 위치 접근, Jeep 원격 제어 같은 제조사별 보안 취약점도 이미 여러 건 문서화되어 있어요.
• 이 개발자는 직접 DCM과 GPS 유닛을 물리적으로 제거했어요. OTA 업데이트와 긴급 SOS 기능이 꺼지는 트레이드오프가 생기지만, DCM Bypass Kit을 쓰면 마이크 기능은 살릴 수 있어요. GPS 제거는 보너스 효과도 있었는데, CarPlay가 잘못된 위치를 표시하는 버그가 차량 내장 GPS 때문이었고, 뽑아내자마자 해결됐어요.
• 앞으로 나올 차들은 모뎀이 더 깊숙이 통합될 가능성이 높아요. 지금처럼 물리적으로 제거하는 방법이 언제까지 가능할지 모르죠. 내 기기가 무엇을 수집하는지 알고 싶다면, 지금 당장 제조사 개인정보 처리방침부터 읽어보는 게 시작이에요.

Apple이 5년 걸려 만든 보안 장벽, AI와 사람이 5일 만에 뚫었어요

• Apple은 메모리 손상 공격을 막기 위해 MIE(Memory Integrity Enforcement)를 개발하는 데 5년과 수십억 달러를 썼어요. 그런데 연구자들이 AI 도움을 받아 단 5일 만에 Apple M5 실리콘 위에서 이를 우회하는 익스플로잇을 만들어냈어요. 권한 없는 일반 사용자로 시작해서 시스템 콜만으로 루트 권한을 얻는 방식이에요.
• 이 익스플로잇은 ARM MTE(Memory Tagging Extension) 기반의 MIE를 우회하는 데이터 전용 커널 권한 상승 체인이에요. 취약점 두 개와 여러 기법을 조합했고, macOS 26.4.1 베어메탈 환경에서 동작해요. 4월 25일에 버그를 발견하고 5월 1일에 동작하는 익스플로잇을 완성했으니, 속도가 무섭죠.
• iOS와 macOS에서 가장 흔한 취약점 유형은 여전히 메모리 손상이에요. 하드웨어 수준의 방어막을 쌓아도, AI가 취약점 탐색을 도와주는 시대에는 공격 속도 자체가 달라졌어요. Apple이 패치를 배포하기 전까지 기술 세부 내용은 공개되지 않을 예정이에요.

WAVE 03 446 pts · 115 comments

RTX 5090을 맥북에 꽂아봤어요. 되긴 됩니다. 근데 왜 이렇게 복잡하냐고요.

• Thunderbolt는 USB-C로 PCIe를 터널링해서 최대 40Gbps 대역폭으로 외장 GPU를 연결할 수 있어요. 그런데 Apple Silicon 맥에는 NVIDIA나 AMD GPU 드라이버가 아예 없어요. 그래서 이 개발자는 QEMU로 Linux ARM64 가상 머신을 띄우고, PCI 패스스루로 GPU를 VM에 직접 연결하는 방식을 택했어요.
• 구현 과정에서 PCI BAR(Base Address Registers)와 DMA(Direct Memory Access) 지원을 직접 엔지니어링해야 했어요. 대안으로 시도한 tinygrad eGPU 드라이버는 M4 Pro의 네이티브 Metal 추론 대비 약 10배 느린 성능을 보였어요. 동작은 하지만, 실용적인 수준은 아니에요.
• 이 방식의 장기적인 가능성은 QEMU 업스트림 통합과 Apple의 드라이버 지원 여부에 달려 있어요. 지금은 고도로 실험적인 우회책이고, 성능 오버헤드도 상당해요. 그래도 '왜 안 되는지'를 끝까지 파고들어서 '어떻게든 되게 만든' 과정 자체가 읽을 만해요.
