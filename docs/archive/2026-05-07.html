• 연구에 따르면 주요 AI 모델은 자신의 결과물에 대해 약 50% 과신하는 경향이 있어요. 스스로 틀렸다고 말해주지 않아요. 몇 달을 쏟아부은 시스템이 근본부터 잘못 설계된 경우가 실제로 생기고 있어요.
• 조직의 인센티브 구조가 문제를 키워요. 정확성보다 눈에 보이는 진척을 선호하는 문화에서는 AI가 만든 엉터리 결과물이 오래 살아남아요. 전문 지식 없이 AI로 소프트웨어를 만드는 건, 비전문가가 자기 분야에서 AI를 쓰는 것보다 훨씬 위험해요.

💡 오늘의 인사이트

• Claude Code 같은 AI 코딩 에이전트가 신뢰할 만해질수록, 프로덕션 코드도 줄 단위로 검토하지 않게 된다는 게 그의 솔직한 고백이에요. 그는 이걸 대형 조직에서 다른 팀의 코드를 신뢰하는 것과 비슷하게 본다고 해요. 문서와 테스트로 판단하는 거죠.
