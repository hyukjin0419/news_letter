• 미국의 GPU 수출 규제가 오히려 중국 기업들을 오픈 배포 전략으로 밀어넣었고, 결과적으로 생태계 확산 면에서 더 유리한 위치를 만들어줬다는 아이러니가 있어요.

반복 업무를 새벽에도 혼자 돌려주는 도구가 나왔어요

• Kimi Work는 내장 Cron engine을 탑재해서 정해진 시간에 자동으로 워크플로우를 실행해줘요. 별도 스케줄러 서버를 띄울 필요가 없어요.
• LLM Agent를 호출해서 매일 아침 브리핑 초안을 작성하거나, Python 스크립트를 실행해서 데이터를 가공하는 작업을 24시간 백그라운드에서 처리해줘요.
• 코드 한 줄 없이 반복 업무를 자동화할 수 있다는 점에서, 개발자보다 오히려 기획자나 데이터 분석가에게 더 강력한 도구가 될 수 있어요.

💡 오늘의 인사이트

오픈 모델은 공짜가 아니에요, 추론 비용이 진짜 청구서예요

• Kimi K3 같은 오픈 웨이트 모델은 모델 가중치 자체는 무료지만, 실제 추론 비용은 100만 토큰당 3달러에서 15달러 수준이에요. 트래픽이 늘수록 COGS가 매출과 함께 올라가는 구조예요.
• Nvidia는 AI 인프라를 '토큰 공장'으로 프레이밍하면서 tokens-per-second, 토큰당 비용 같은 지표를 전면에 내세우고 있어요. AI 인프라 투자 판단 기준이 바뀌고 있다는 신호예요.
• 미국 사이버보안 분야에서 자국 모델 사용 제한이 오히려 중국 AI 의존도를 높이는 역설적 상황이 벌어지고 있어요. 규제가 보안을 강화하려다 취약점을 만드는 케이스예요.
