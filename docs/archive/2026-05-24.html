WAVE 03 331 pts · 102 comments

div 대신 dl, 알고 쓰면 접근성이 공짜로 따라와요

• dl 태그는 이름-값 쌍을 표현할 때 쓰는 HTML 요소예요. dt는 용어(이름), dd는 설명(값)이에요. API 응답 데이터나 상세 정보 목록을 마크업할 때 div 중첩보다 훨씬 의미 있는 구조를 만들 수 있어요.
• 스크린리더가 dl을 인식하면 목록 길이, 현재 위치를 자동으로 읽어줘요. 별도 작업 없이 접근성이 생기는 거예요. 다만 브라우저와 스크린리더 조합에 따라 지원이 고르지 않아서, 아직은 폴백 경험도 함께 고려해야 해요.
• 스타일링이 필요하면 dt와 dd를 div로 묶는 것만 허용돼요. 다른 태그로 감싸면 유효하지 않은 마크업이 돼요.

💡 오늘의 인사이트

시맨틱 마크업은 '있으면 좋은 것'이 아니에요. 구조를 제대로 잡으면 접근성, SEO, 유지보수성이 한 번에 따라와요. 다음에 키-값 형태 UI를 만들 때, div 쓰기 전에 dl 한번 떠올려 보세요. 코드가 훨씬 읽기 좋아질 거예요.
