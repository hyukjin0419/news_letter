60년 동안 매일 조금씩 그린 지도가 있다고요?

• 1963년 여름, 한 예술가가 심심풀이로 그리기 시작한 상상 속 도시 지도가 지금은 4000장이 넘는 패널로 이루어진 거대한 원형 작품이 됐어요. 좌표계로 위치를 고정하고, 패널은 계속 수정하는 방식이라 지도는 살아 숨쉬듯 변해요.
• 창작 방향은 약 100장짜리 카드 덱이 결정해요. 카드 한 장에는 크기 변경, 색칠 방법, 재료 조달, 수치 조정, 규칙 변경 같은 다섯 가지 범주의 지시가 담겨 있죠. 처음엔 단순한 난수 생성기였는데, 지금은 예술적 결정을 이끄는 정교한 시스템이 됐어요.
• 새 패널은 기존 패널의 중심에서 동서남북 방향으로만 붙여요. 이 단순한 규칙 하나가 전체 작품의 원형 구조를 60년 넘게 유지시켜 왔어요.

💡 오늘의 인사이트

개발자로서 이 프로젝트가 남다르게 느껴지는 건, 시스템 설계 때문이에요. 카드 덱은 일종의 제약 기반 알고리즘이고, 좌표 고정 규칙은 데이터 무결성 전략이에요. 거창한 계획 없이 단순한 규칙 몇 가지만으로 수십 년짜리 프로젝트를 굴러가게 만든 거죠. 지금 내가 만드는 시스템도 10년 뒤에 누군가 이어받아 쓸 수 있을 만큼 단순하고 명확한가, 한번 돌아볼 만한 질문이에요.

WAVE 02 192 pts · 66 comments

스와이프 키보드 데이터, 이제 MIT 라이선스로 공짜예요

• FUTO가 2024년 8월부터 자원 참여자들의 스와이프 입력 데이터를 모았어요. 참여자들이 주로 위키피디아 문장을 단어 단위로 스와이프하는 방식이었고, 총 100만 건 이상의 데이터를 수집했어요.
• 품질 필터링을 거친 100만 건 데이터셋을 2025년 3월 HuggingFace에 MIT 라이선스로 공개했어요. 스와이프 타이핑 모델 학습과 평가에 바로 쓸 수 있는 형태예요.
• 데이터 수집 창구는 swipe.futo.org였고, 참여자 동의를 받은 뒤 진행했어요. 오픈소스 키보드 모델 연구에 관심 있다면 지금 당장 써볼 수 있어요.

💡 오늘의 인사이트

모바일 키보드 UX나 자연어 입력 관련 사이드 프로젝트를 생각해 본 적 있다면, 이 데이터셋은 진짜 좋은 출발점이에요. 직접 데이터를 모으는 게 얼마나 힘든 일인지 다들 알잖아요. 누군가 이미 100만 건을 정제해서 공짜로 풀어줬으니, 이 기회를 그냥 지나치기엔 좀 아깝죠.

WAVE 03 68 pts · 2 comments

빨간 물결선 하나가 글쓰기를 바꿨어요

• 마이크로소프트 워드 개발자 토니 크루거가 맞춤법 오류에 빨간 물결선, 문법 오류에 초록 물결선을 표시하는 기능을 만들었어요. 지금은 너무 당연해서 없으면 오히려 어색하죠.
• 이 기능이 나오기 전엔 맞춤법 검사가 작업을 멈추게 하는 블로킹 방식이었어요. 크루거는 이걸 실시간 시각 표시로 바꿔서 사용자가 글 쓰는 흐름을 끊지 않도록 했어요. 지그재그 선 모양은 일반 밑줄과 구별하기 위해 의도적으로 선택한 디자인이에요.
• 빨강과 초록을 구분하기 어려운 색각 이상 사용자는 전체의 약 3% 정도예요. 다행히 물결선의 지그재그 모양 자체가 색과 무관하게 시각적으로 구별되도록 설계돼 있어요.

💡 오늘의 인사이트

UX에서 비동기 피드백이 얼마나 강력한지를 보여주는 사례예요. 사용자를 기다리게 하지 않고, 작업 흐름 안에서 자연스럽게 정보를 전달하는 것. 우리가 만드는 서비스에도 똑같이 적용돼요. 에러 메시지를 폼 제출 후에 한꺼번에 보여주는 대신, 입력하는 순간 바로 알려주는 것처럼요. 수십 년 전 워드 개발자가 이미 답을 알고 있었네요.
