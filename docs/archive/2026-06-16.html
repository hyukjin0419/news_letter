링크드인 채용 DM, 클릭 전에 한 번만 더 의심해 보세요

• 실제로 존재하는 개발자와 리크루터의 신원을 도용한 공격이에요. 깃허브 레포를 검토해 달라는 요청처럼 보이지만, app/test/index.js 안에 악성 코드가 숨어 있었죠. 테스트 파일처럼 위장해서 눈에 잘 안 띄어요.
• 무서운 건 코드를 직접 실행하지 않아도 뚫린다는 거예요. npm install만 해도 prepare 스크립트가 자동으로 돌면서 원격 서버에서 임의 코드를 내려받아 실행해요. URL도 문자열 조각을 이어 붙이는 방식으로 탐지를 피했고요.
• 이 개발자가 피해를 막을 수 있었던 건 읽기 전용 AI 에이전트 덕분이었어요. read, grep, find, ls만 허용한 제한된 환경에서 코드를 분석했고, 실행 없이 위협을 발견했죠. 신고 후에도 레포는 한동안 살아 있었어요.

💡 오늘의 인사이트

채용 과정에서 코드 과제를 받는 건 이제 흔한 일이에요. 그런데 피로하거나 바쁠 때 npm install 한 번이 내 컴퓨터 전체를 열어주는 문이 될 수 있어요. 낯선 레포는 반드시 코드를 먼저 읽고, 가능하면 격리된 환경이나 읽기 전용 도구로 먼저 살펴보는 습관을 들이는 게 좋아요. 귀찮음보다 내 개인 정보와 회사 자산이 훨씬 소중하니까요.

전구로 금서 도서관을 만든 개발자 이야기

• 스마트 전구를 와이파이 액세스 포인트로 바꿔서 금서를 배포하는 프로젝트예요. ESP32C3 기반 전구에 Tasmota 오픈소스 펌웨어를 올리고 웹 서버를 얹었어요. 전구로 불도 켜고 책도 읽히는 거죠.
• 가장 큰 난관은 저장 공간이었어요. 플래시 메모리가 4MB밖에 안 되거든요. SPIFFS 파일시스템 압축으로 이 한계를 넘었고, 클라우드 없이 로컬에서 모든 걸 처리해요.
• 앞으로는 분산 해시 테이블을 활용한 메시 네트워킹을 붙여서 여러 전구가 서로 연결되는 구조를 만들 계획이에요. 하드웨어 해킹과 소프트웨어가 만나는 지점이 꽤 흥미롭죠.

💡 오늘의 인사이트

기술이 꼭 거창한 문제를 풀어야만 의미 있는 건 아니에요. 이 프로젝트는 작은 마이크로컨트롤러 하나로 '정보 접근'이라는 가치를 구현했어요. 내가 쓰는 기술로 어떤 가치를 만들 수 있을지 가끔 엉뚱하게 상상해 보는 것, 개발자로서 재미있게 오래 살아남는 방법 중 하나라고 생각해요.

IP 주소 없이 기기끼리 연결된다면 어떨까요, Iroh 1.0이 그걸 해요

• IP 주소 대신 암호화 키로 기기를 식별해요. 방화벽 뒤에 있어도 연결되고, 주소가 바뀌어도 기기가 직접 제어하는 구조라 훨씬 안정적이에요. QUIC 멀티패스로 여러 경로를 하나의 연결 안에서 동시에 관리하고 동적으로 전환해요.
• 데이터의 95%가 클라우드를 거치지 않고 기기끼리 직접 전송돼요. 클라우드 비용이 줄고 지연도 낮아지죠. BLE, LoRa, Tor 같은 커스텀 전송 방식도 붙일 수 있고, WASM으로 브라우저에서도 돌아요.
• 65번의 버전을 거쳐 1.0이 됐고, 이미 수백만 기기에 배포돼 있어요. 마이너 버전에서는 와이어 프로토콜과 언어 API가 안정적으로 유지되고, 2026년 9월까지 지원 일정도 명확히 잡혀 있어요. Rust, Python, Node.js, Swift, Kotlin을 지원해요.

💡 오늘의 인사이트

P2P 연결이 필요한 프로젝트를 만들 때 항상 NAT 통과, 방화벽, 주소 변경 문제가 발목을 잡죠. Iroh는 이 문제들을 IP 주소라는 개념 자체를 바꾸는 방식으로 풀었어요. 당장 쓸 일이 없더라도 로컬 우선 앱이나 기기 간 직접 통신이 필요한 순간이 오면 꺼내 볼 만한 선택지예요.
