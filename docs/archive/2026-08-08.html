과제 풀이 AI가 62초짜리 명령어를 만났을 때

• DeepSeek V4 Flash 0731은 추론 강도를 Max, High, Low 세 단계로 나눠 쓸 수 있어요. ARC-AGI-1 기준으로 Max는 89%, Low는 84%라 비용 대비 성능을 직접 골라 쓸 수 있죠.
• 과제 하나당 비용은 ARC-AGI-1이 $0.02, 더 어려운 ARC-AGI-2가 $0.04예요. 추론 단계를 낮추면 비용도 줄고 속도도 빨라지니, 실제 서비스에 붙일 때 레벨 선택이 꽤 중요한 설계 결정이 돼요.
• ARC-AGI-2에서는 Max 기준 61.4%로 뚝 떨어져요. 벤치마크 점수가 높다고 모든 문제에 잘 맞는 건 아니라는 걸 다시 한번 확인시켜 주는 숫자예요.

명령어 하나로 62초를 버티는 CPU, 어떻게 가능할까요

• Assembly Hall of Shame은 x86 명령어 중 가장 느린 것을 찾는 연구예요. 현재 챔피언은 fxrstor64로, 경쟁 코어가 PCIe 버스를 포화시키는 '해머 기법'을 함께 쓰면 무려 1980억 사이클, 실시간으로 62초가 걸려요.
• 느린 명령어들의 공통점이 있어요. MMIO 공간 접근, 비정렬 메모리, 비정규 부동소수점 값, 하드웨어 엔트로피 고갈처럼 하드웨어가 '예상 밖 상황'을 만날 때 마이크로코드 보조 경로로 빠지면서 시간이 폭발적으로 늘어나요.
• 이 연구는 단순한 호기심을 넘어서 실제 위협도 돼요. 특별한 장비 없이 일반 하드웨어만으로 PCIe 패브릭을 고갈시키는 서비스 거부 벡터가 될 수 있거든요.

그리스어 단어를 클릭 한 번으로 분석해 주는 고전 도서관

• Ancient Library는 그리스어 767편, 라틴어 293편, 총 1,060개 고전 텍스트를 모아둔 웹 플랫폼이에요. 단어를 클릭하면 어근, 형태소, 사전 정의까지 바로 보여줘요.
• 라틴어는 Lewis & Short, 그리스어는 Liddell-Scott-Jones 사전을 연결해서 학술 수준의 정보를 제공해요. 서사시, 비극, 철학, 역사 등 20개 이상의 장르로 정리돼 있어서 원하는 텍스트를 찾기도 쉬워요.
• 개발적으로 보면 이런 인터랙티브 텍스트 파서는 형태소 분석과 사전 API 연동의 좋은 레퍼런스가 돼요. 고전어처럼 어형 변화가 복잡한 언어를 어떻게 처리했는지 살펴보면 자연어 처리 설계에 힌트를 얻을 수 있어요.
