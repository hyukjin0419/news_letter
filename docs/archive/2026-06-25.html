OpenAI가 직접 칩을 만들었어요. 엔비디아 없이도 AI를 돌릴 수 있을까요?

• OpenAI가 Broadcom과 함께 만든 첫 번째 자체 추론 칩 Jalapeño를 공개했어요. 학습이 아닌 inference, 즉 이미 만들어진 모델을 실제로 돌리는 작업에 특화되어 있어요.
• 초기 테스트에서 현재 최고 사양 대비 performance-per-watt가 눈에 띄게 좋다고 해요. 전력 효율이 곧 운영 비용이니까, 이게 실제로 검증되면 꽤 큰 변화예요.
• 다만 아직 테스트 단계고, 모델 사전 학습처럼 무거운 작업은 여전히 엔비디아 GPU가 필요해요. 엔비디아 의존도를 완전히 벗어나기엔 아직 갈 길이 있어요.

💡 오늘의 인사이트

구글, 아마존에 이어 OpenAI까지 자체 칩을 만들기 시작했어요. 클라우드 AI 서비스를 쓰는 입장에서는 당장 바뀌는 게 없어 보이지만, 장기적으로는 API 가격 구조나 성능 한계가 달라질 수 있어요. 지금 쓰는 AI 서비스의 하드웨어 의존성을 한 번쯤 살펴보는 게 좋을 것 같아요.

WAVE 02 332 pts · 50 comments

Ruby로 AI 붙이는 게 이렇게 편해져도 되나요? RubyLLM 써봤어요?

• RubyLLM은 OpenAI, Claude, Gemini 등 12개 이상의 AI 제공사를 하나의 인터페이스로 묶어주는 Ruby 프레임워크예요. 제공사가 바뀌어도 코드를 거의 안 고쳐도 돼요.
• 채팅, 이미지 분석, 음성 변환, 임베딩, 콘텐츠 검수까지 한 곳에서 처리할 수 있고, Tools와 Agents로 AI가 직접 Ruby 메서드를 호출하게 만들 수도 있어요. 의존성은 Faraday, Zeitwerk, Marcel 세 개뿐이에요.
• Rails 프로젝트라면 ActiveRecord 연동과 기본 채팅 UI까지 제공해요. 800개 이상의 모델 정보와 가격 데이터도 내장되어 있어서 모델 선택 기준을 잡는 데도 도움이 돼요.

💡 오늘의 인사이트

AI 제공사 API를 직접 붙이다 보면 나중에 제공사를 바꾸거나 여러 곳을 동시에 쓸 때 코드가 엉망이 되는 경우가 많아요. RubyLLM처럼 추상화 레이어를 두는 방식은 유지보수 측면에서 꽤 현명한 선택이에요. Ruby 프로젝트가 아니더라도, 지금 AI를 직접 연동하고 있다면 이런 구조를 참고해볼 만해요.

WAVE 03 830 pts · 251 comments

DNS 비용 0원이 됐어요. Bunny DNS가 완전 무료로 바뀌었거든요.

• Bunny DNS가 쿼리당 과금을 완전히 없앴어요. 계정당 500개 도메인까지 무제한 쿼리를 무료로 쓸 수 있어요. 현재 30만 개 도메인, 월 2000억 건의 쿼리를 처리하고 있어요.
• 단순한 DNS 호스팅이 아니에요. 레이턴시 데이터와 헬스 체크를 기반으로 한 스마트 라우팅, JavaScript 기반 동적 라우팅까지 지원해요. CDN 연동도 DNS 레코드에서 클릭 한 번으로 켤 수 있어요.
• 다른 DNS 제공사에서 옮겨올 때 자동 존 스캔 기능으로 마이그레이션이 편해졌어요. 플랫폼을 실제로 사용하는 계정에는 월 최소 1달러 요금이 적용돼요.

💡 오늘의 인사이트

DNS 비용이 크지 않아 보여도 도메인이 많아지면 은근히 쌓여요. 지금 Route53이나 Cloudflare DNS를 쓰고 있다면 Bunny DNS로 옮기는 게 비용 면에서 합리적일 수 있어요. 특히 CDN이나 보안 기능을 함께 쓸 계획이라면 통합 관리 측면에서도 한번 검토해볼 만해요.
